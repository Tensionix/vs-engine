# Изменения

[English](CHANGELOG_EN.md) · [О программе](README_RU.md)

## 3.1.0

- Вопрос о дополнительных компонентах при запуске: кнопка **ОТКРЫТЬ SETUP** закрывает его и сразу открывает лист SETUP.
  «Позже» по-прежнему до следующего запуска: пока компонента нет, вопрос задаётся снова.

## 3.0.0

**Одна программа.** Audion VS Engine и Audion VS Engine Lite теперь одна программа. Нейросетевые пресеты показываются по
машине: при видеокарте NVIDIA RTX СЕРВИС предлагает «Установить MLRT»; без карты и без MLRT их в окне нет.

**Новое**
- Окно на Avalonia (`Start.exe`, `App\AudionVSEngine.exe`): палитры, пресеты группами по виду обработки, формы с
  ползунками, карточки кодера, запомненные пути с историей и закреплением, терминал с ходом каждого кадра, СТОП.
- Превью: кадр из середины видео Источника до и после пресета со значениями формы, считается само, когда форму оставили в
  покое; до, после или рядом; видео Источника по очереди.
- Консольная команда `vs_cli.cmd`: каждая операция, итог в JSON, коды выхода, `--dry-run`, файл остановки, `frame` — кадр
  до и после в PNG; `describe`, `list`, `map`, `components`, `plan`.
- Пресеты: IMAX 70 мм, Анаморфот, Полароид; с MLRT — Шумодав DPIR, Real-ESRGAN 2x, Пересборка мягкого HD 2x. Всего
  28 пресетов. Интерполяции RIFE полного издания 2.0.3 нет: на RTX 5070 TensorRT (10.16, 11.1, TensorRT-RTX 1.5) строит
  неверные промежуточные кадры; DirectML даёт верные только через ONNX Runtime, а его плагин vs-mlrt есть лишь под
  старый интерфейс, который VapourSynth R80+ не загружает; на процессоре новый кадр 4K считается 1,28 с — около
  получаса на минуту 24p, удвоенную до 48p. Подробно — [Решения](DECISIONS_RU.md#интерполяции-кадров-нет).
- Шумодавы измеряют шум исходника и усиливаются вместе с ним (`noise=auto`); `noise=fixed` оставляет настройки.
- Пресет идёт по файлу или по всей папке с подпапками; результаты сохраняют её папки.
- «Сохранить профиль» на странице пресета.
- SETUP в шапке: дополнительные компоненты — VapourSynth, его плагины, FFmpeg, MLRT при карте RTX — с версиями,
  УСТАНОВИТЬ, ОБНОВИТЬ и УСТАНОВИТЬ ВСЁ; при каждом запуске окно предлагает поставить те, которых ещё нет, или говорит,
  где SETUP.
- Установщики говорят, что скачают, до начала; движок можно убрать в Корзину.

**Изменено**
- FFmpeg по драйверу NVIDIA: самая новая стабильная сборка Gyan, не ниже 9.0.2, без видеокарты NVIDIA и с LTS-драйвером
  610.88 и новее; более новая, не прошедшая пробу NVENC, возвращается к 9.0.2. Ниже 610.88 прежняя ветка сохраняет работу
  NVENC, а установщик, план закачки и бейдж FFmpeg говорят, что доступны не все операции. Окно сравнивает FFmpeg с самым
  новым выпуском; SETUP обновляет её.
- Самый новый стабильный VapourSynth с плагинами под его интерфейс; набор плагинов не сдвигает ядро.
- BM3D на видеокарте через Vulkan, на карте любого производителя; без неё — на процессоре. ОБРАБОТКА — Авто / Процессор /
  Видеокарта — стоит только у пресетов, где что-то меняет.
- Результат ложится в `<Назначение>\<Палитра>\<пресет>_<кодер>\`, имя исходника сохраняется.
- Готовый результат пропускается, если не включено «Перезаписать»; результат пишется под своим именем, пока не дописан.
- Выход сохраняет диапазон исходника — через фильтры и в кодировщике.
- У зерна постоянное начальное число: один файл даёт одни и те же кадры.
- Индексы исходников пишутся в папку программы, а не рядом с исходником.
- Обратный телесин отказывает источнику меньше 29 к/с.
- RAW камер в Источнике — ProRes RAW, ARRIRAW, Sony RAW / X-OCN, RED R3D, Nikon N-RAW, Blackmagic RAW, Canon Cinema RAW —
  называется одной строкой с программой, которая его открывает, и её страницей; движок его не читает: Источник только
  из него получает отказ до начала, среди других видео он проваливается сам по себе; превью говорит то же.
- Значение вне диапазона или не из вариантов получает отказ с причиной.

**Исправлено**
- ProRes в MXF останавливался до первого кадра, если у источника звук AAC или 44,1 кГц: в MXF звук идёт PCM 24 бит 48 кГц.
- Исходники прежней сборки FFmpeg убираются, когда исходники новой на месте.
- СТОП больше не оставляет недописанный файл, который следующий прогон принимал за готовый.
- Папки программы очищаются через Корзину.
- Три встроенных профиля называли несуществующий кодер; теперь у них `h264_crf14`.
- Real-ESRGAN: модели «Общая» и «Общая с шумодавом» запускали аниме-модель — общих моделей Real-ESRGAN в vs-mlrt нет;
  их больше нет, по умолчанию «Аниме», а модель, которой нет в vs-mlrt, отклоняется по имени.
